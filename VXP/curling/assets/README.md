# Curling Overlay Asset

Copy the approved transparent PNG into this folder with the exact filename:

`pirates-overlay.png`

Expected repository path:

`VXP/curling/assets/pirates-overlay.png`

The overlay should use the same aspect ratio and final pixel dimensions desired for the exported image. The branding engine uses the overlay dimensions as the output canvas dimensions and scales/crops the AI image underneath it.

Recommended:

- PNG with transparency
- 2048 × 2048 for square output, or the exact dimensions of the approved overlay
- Keep all logos, event text, and borders inside the safe area
- Use lowercase filename exactly as shown
